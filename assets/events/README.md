# Olay görselleri

Rastgele olay kataloğu şu an bilinçli olarak boştur. Motor
`lib/systems/events/event_system.dart`, içerik sınırı
`lib/systems/events/event_catalog.dart` içindedir.

Yeni bir olay paketi kendi görselini bu klasöre ekleyip
`lib/ui/events/event_artwork.dart` içinde eşleyebilir. Görsel eklenmezse kart metinle
çalışmaya devam eder.
